# اپ اندروید شادبیب 📚

اپلیکیشن اندروید نیتیو برای پلتفرم مطالعه اجتماعی **شادبیب** — ساخته‌شده با Kotlin و Jetpack Compose (Material 3) با طراحی کاملاً مستقل از نسخه وب.

## ✨ امکانات

- **تایمر مطالعه** با انتخاب درس، توقف/ادامه و ثبت پارت (حتی بعد از بستن اپ، تایمر از دست نمی‌ره)
- **ثبت دستی** زمان مطالعه
- **مدیریت دروس** با رنگ و آیکون
- **تسک‌ها**: امروز / آینده / تاریخچه با اولویت‌بندی و تاریخ جلالی
- **ساعت بیداری** با TimePicker
- **مود و استاتوس** (ایموجی‌های عمومی و درسی)
- **استریک 🔥** و آمار روزانه/هفتگی
- **نمودار هفتگی** و **تایم‌لاین ساعتی** (امروز/دیروز) و **گزارش روزانه**
- **دوستان**: دنبال‌کردن، وضعیت آنلاین، جزئیات مطالعه و تسک‌های دوستان
- **چت گروهی**: ارسال، ریپلای، ویرایش، حذف + اعلان‌ها (polling)
- **فید یادداشت‌ها**: انتشار، لایک، کامنت، جستجو و مرتب‌سازی
- **موزیک‌پلیر**: پخش در پس‌زمینه با نوتیفیکیشن (Media3)، مینی‌پلیر، شافل/تکرار، پلی‌لیست‌ها، آپلود با کاور، لایک و جستجو
- **جزوه‌ها**: آپلود چند‌عکسی با دسته‌بندی، گالری ورق‌زدنی، لایک و کامنت
- **RTL کامل**، فونت **وزیرمتن**، اعداد و تاریخ **فارسی/جلالی**
- تم **تیره و روشن** (پیرو تنظیمات سیستم)

## 🏗 معماری

| لایه | تکنولوژی |
|---|---|
| UI | Jetpack Compose + Material 3 |
| الگو | MVVM (ViewModel + StateFlow) |
| شبکه | OkHttp + org.json |
| تصاویر | Coil |
| پخش موزیک | Media3 ExoPlayer + MediaSessionService |
| ذخیره‌سازی | DataStore Preferences |
| ناوبری | Navigation Compose |

آدرس API در فایل `app/src/main/java/ir/shadbib/app/core/Api.kt` تنظیم شده:

```kotlin
const val BASE = "https://beautifulrabor.ir/shadbib/api.php"
const val MEDIA_BASE = "https://beautifulrabor.ir/shadbib/"
```

اگه دامنه رو عوض کردی فقط همین دو خط رو تغییر بده.

## 🔨 بیلد

پیش‌نیاز: Android Studio (یا JDK 17 + Android SDK 34)

```bash
# ساخت نسخه release (امضاشده با keystore پروژه)
./gradlew assembleRelease
# خروجی: app/build/outputs/apk/release/app-release.apk
```

یا پروژه رو توی Android Studio باز کن و از منوی Build گزینه Build APK رو بزن.

### 🔑 امضا (Keystore)

فایل keystore در مسیر `keystore/shadbib.keystore` قرار داره:

- **Store/Key password:** `shadbib2026`
- **Alias:** `shadbib`

⚠️ این فایل رو گم نکن — برای انتشار آپدیت‌های بعدی (نصب روی نسخه قبلی) باید APK با همین keystore امضا بشه. برای انتشار عمومی بهتره پسورد رو عوض کنی و keystore شخصی خودت رو بسازی.

## 📁 ساختار پروژه

```
app/src/main/java/ir/shadbib/app/
├── core/        # Api، Store (توکن/تایمر)، تاریخ جلالی و فرمت فارسی
├── data/        # مدل‌های داده و پارس JSON
├── player/      # سرویس پخش موزیک (Media3)
└── ui/
    ├── auth/      # ورود / ثبت‌نام با کد دعوت
    ├── home/      # تایمر، بیداری، مود، دروس، اعلان‌ها
    ├── tasks/     # تسک‌ها
    ├── community/ # دوستان، چت، یادداشت‌ها
    ├── library/   # موزیک، جزوه‌ها، پلیر
    ├── profile/   # آمار، نمودار، گزارش، خروج
    ├── nav/       # ناوبری پایین
    ├── theme/     # پالت، تایپوگرافی، شکل‌ها
    └── components/# کامپوننت‌های مشترک
```
