شادبیب اندروید v2.3.0 — راهنمای بیلد
=====================================
این سورس کامل و آمادهٔ بیلد است (کی‌استور امضا هم داخلش هست).

روش ۱ — Android Studio (پیشنهادی):
  1. پوشه را در Android Studio باز کن (Open Project)
  2. صبر کن Gradle Sync تمام شود
     (بار اول گریدل 8.7 دانلود می‌شود — اینترنت لازم است)
  3. Build → Build Bundle(s)/APK(s) → Build APK(s)
  4. خروجی: app/build/outputs/apk/release/app-release.apk

روش ۲ — خط فرمان:
  این بسته فایل gradlew و gradle-wrapper.jar ندارد (باینری است).
  یک‌بار در ریشهٔ پروژه اجرا کن تا ساخته شوند:
      gradle wrapper --gradle-version 8.7
  بعد از آن:
      ./gradlew assembleRelease        (ویندوز: gradlew.bat assembleRelease)
  اگر پروژه را یک‌بار در Android Studio باز کنی، خودش رپر را می‌سازد.

پیش‌نیازها:
  - JDK 17 (اجباری — jvmTarget 17)
  - Android SDK Platform 34
  - Android Studio Koala یا بالاتر (AGP 8.5.2)

local.properties:
  عمداً داخل بسته نیست چون مسیر SDK روی سیستم تو فرق دارد.
  Android Studio خودکار می‌سازدش. برای خط فرمان دستی بساز:
      sdk.dir=/path/to/Android/Sdk

امضا:
  خودکار با keystore/shadbib.keystore (تنظیمات داخل app/build.gradle).
  هر دو بیلد‌تایپ debug و release با همین کلید امضا می‌شوند، پس
  می‌توانی روی نسخهٔ نصب‌شدهٔ قبلی مستقیم آپدیت کنی.
