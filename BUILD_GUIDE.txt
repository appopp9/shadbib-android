شادبیب اندروید v2.4.0 — راهنمای بیلد
=====================================
سورس کامل و آمادهٔ بیلد. کی‌استور امضا داخل بسته هست.

پیش‌نیازها
----------
  - JDK 17  (اجباری — jvmTarget 17 است. با JDK 21/25 بیلد شکست می‌خورد.)
  - Android SDK Platform 34
  - Android Studio Koala یا بالاتر (AGP 8.5.2 / Kotlin 2.0.20 / Gradle 8.7)

روش ۱ — Android Studio (پیشنهادی)
---------------------------------
  1. Open Project و همین پوشه را انتخاب کن
  2. صبر کن Gradle Sync تمام شود (بار اول گریدل ۸.۷ دانلود می‌شود — اینترنت لازم است)
  3. Build → Build Bundle(s)/APK(s) → Build APK(s)
  4. خروجی: app/build/outputs/apk/release/app-release.apk

روش ۲ — خط فرمان
-----------------
  این بسته gradlew و gradle/wrapper/gradle-wrapper.jar ندارد (فایل باینری است
  و داخل زیپ متنی جا نمی‌شود). یک‌بار در ریشهٔ پروژه اجرا کن:

      gradle wrapper --gradle-version 8.7

  بعد از آن:

      ./gradlew assembleRelease          (ویندوز: gradlew.bat assembleRelease)

  اگر پروژه را یک‌بار در Android Studio باز کنی، رپر خودکار ساخته می‌شود و
  دیگر به این مرحله نیازی نیست.

local.properties
----------------
  عمداً داخل بسته نیست چون مسیر SDK روی هر سیستم فرق دارد.
  Android Studio خودش می‌سازدش. برای خط فرمان دستی بساز:
      sdk.dir=/path/to/Android/Sdk
  (ویندوز: sdk.dir=C:\\Users\\NAME\\AppData\\Local\\Android\\Sdk)

تغییرات این نسخه (۲.۳.۵) — ورود و ثبت‌نام
────────────────────────────────────────────────────────────
سه فایل تغییر کرده، همگی در:
  app/src/main/java/ir/darshub/app/ui/auth/

1) IranPhone.kt
   + ltr(text)      — متن را در LRI…PDI یونیکد می‌پیچد تا وسط جملهٔ فارسی
                      جابه‌جا نشود
   + maskLtr(raw)   — نسخهٔ چپ‌چین mask()
   + GROUP_1 / GROUP_2 — نقاط گروه‌بندی 0912 345 6789

2) NeoUi.kt
   + PhoneDigitsTransformation — گروه‌بندی زندهٔ ارقام هنگام تایپ.
     مقدار واقعیِ state همان ۱۱ رقم خالص می‌ماند؛ فاصله‌ها فقط نمایشی‌اند و
     به سرور نمی‌روند.
   ~ PhoneField — کل ردیف با CompositionLocalProvider روی LayoutDirection.Ltr
     قفل شد. نکته: صرفاً textAlign = Start کافی نبود، چون در چیدمان RTL خودِ
     Start یعنی «راست». باید جهت چیدمان عوض می‌شد نه ترازِ متن.
   ~ NeoOtpBoxes — همین قفل روی جعبه‌های کد هم اعمال شد. در کد قبلی کامنت
     "Left to right on purpose" بود ولی چون اپ RTL است Row بی‌صدا برعکس
     می‌شد و اولین رقمِ تایپ‌شده در جعبهٔ سمت راست می‌نشست.

3) AuthFlow.kt
   ~ mask() → maskLtr() در جملهٔ «کد ۶ رقمی را به … فرستادیم»
   ~ رفتار dev_code: اگر سرور کد آزمایشی برگرداند، حالا خودکار در فیلد پر
     می‌شود با پیام «پیامک روی سرور خاموش است — کد خودکار پر شد».
     وقتی SMS_ENABLED روی سرور true شود، dev_code دیگر برنمی‌گردد و این
     مسیر خودبه‌خود غیرفعال می‌شود — نیازی به بیلد مجدد نیست.

هیچ دپندنسی جدیدی اضافه نشده. AuthScreen.kt و core/Api.kt دست‌نخورده‌اند،
پس MainActivity و بقیهٔ صفحه‌ها تغییری نمی‌خواهند.

⚠ یادآوری سمت سرور
  «حالت آزمایشی» یک سوییچ سرور است نه باگ اپ. تا وقتی در config.php مقدار
  SMS_ENABLED برابر false باشد، otp.php کد را در فیلد dev_code برمی‌گرداند.
